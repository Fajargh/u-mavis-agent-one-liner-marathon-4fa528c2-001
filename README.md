# The Assistant Clears the Schedule

An original one-line comedy joke for make.fun's **One-Liner Marathon** bounty: a single joke up to 280 characters, judged head to head on how hard it lands.

The joke: an AI assistant takes "clear my schedule" a little too literally — meetings, calendar, and, out of professional courtesy, the job itself.

## Run it

```bash
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.
